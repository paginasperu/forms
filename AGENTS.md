# Instructions for assistants

Before analyzing or changing this repository, read the project documentation in the private [`paginasperu/docs` repository](https://github.com/paginasperu/docs):

1. [Global README](https://github.com/paginasperu/docs/blob/main/README.md)
2. [Forms README](https://github.com/paginasperu/docs/blob/main/forms/README.md)
3. [Forms changelog](https://github.com/paginasperu/docs/blob/main/forms/changelog.md)

The docs repository explains the project context and current decisions. Verify those against the code before acting; do not rely only on prior chat history.

## Documentation updates

- Update the Forms README when a meaningful change affects current behavior, structure, setup, workflow, or project decisions.
- Add one changelog entry for a meaningful, completed, verified group of related changes.
- Do not create separate documentation entries for isolated trivial fixes or formatting-only edits. Group small related adjustments when they form part of a substantial change.
- Do not edit the Apps Script receiver or change the Sheets contract unless the task explicitly requires it.
- Do not commit or push without the owner's explicit authorization.
